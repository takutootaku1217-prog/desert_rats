- 外装・内装の切替、白／濃灰の重装甲・赤い斜線・青い発光を基調にしたアサルト要塞風の外装表現。

含まれる戦闘用試験コード: ライフル装備・遠距離AI、車載主砲/副砲の発射、試験用サソリ・弾薬補給・装甲計算。全戦闘機能を除外した版ではありません。

## 確認操作

1. Godot でこのフォルダの `project.godot` を開きます。
2. 車両カスタマイズ画面で大型または強化大型シャーシを選びます。
3. `O` キーで外装、`I` キーで内装を表示します。外装は独立した主砲・副砲・五輪、内装は実際の Worker と既存設備の重ね表示を確認します。
4. 大型シャーシの検証用経路を開始し、仲間が上層3室、一本のはしごの上下二区間、地上へ連続して移動し、終了後に通常 AI へ戻ることを確認します。

静的な検証スクリプトは `tools/test_large_vehicle_layout.gd`、`tools/test_large_vehicle_workers.gd`、`tools/test_vehicle_prototype.gd` です。初回移植時にはSmart App Controlの制約で起動していませんでした。その後2026-10-21にLinux Godot 4.6.3で起動エラー・配置ずれを修正し、上記3件と公式ハーネス10件、OpenGLでの実描画を確認しました。Windows 4.7.2とOS実入力は引き続き未検証です。修正内容・条件・画面は [修正検証記録](docs/大型グラフィック_修正検証_2026-10-21.md) を参照してください。
