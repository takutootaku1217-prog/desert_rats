## 移植した検証範囲

- 大型／強化大型シャーシの三層車体座標、五輪、二本の昇降経路、屋根主砲台。
- 外装・内装の切替、白／濃灰の重装甲・赤い斜線・青い発光を基調にしたアサルト要塞風の外装表現。
- プロジェクト内の `assets/fortress_source/` にある外殻・内装・主砲・副砲・車輪の RGBA 素材5点。
- 大型シャーシへ切り替えた際の仲間の上層デッキ経路補正と、視覚確認用の歩行ルート。
- 既存の実 Worker、既存の外装／内装切替、既存の車体移動・車輪回転を使う表示。新しい擬似的な仲間や別ゲームルートは追加していません。

移植しなかったもの: 救助優先、ボス、一般的な戦闘・護衛命令など、今回の大型グラフィック検証と直接関係しない隔離試作機能。

`project.godot` の表示名を `砂漠の移動拠点 大型グラフィック検証 2026-10-21` に設定しました。Godot が起動した場合、このコピーだけの `user://save.json` は次のフォルダになります。

通常版・過去の外観検証版・task-2・task-4 の保存データはコピーも参照もしていません。この版は新規セーブから確認してください。

## 確認操作（起動はまだ行っていません）

1. Godot でこのフォルダの `project.godot` を開きます。
2. 車両カスタマイズ画面で大型または強化大型シャーシを選びます。
3. `O` キーで外装、`I` キーで内装を表示します。外装は独立した主砲・副砲・五輪、内装は実際の Worker と既存設備の重ね表示を確認します。
4. 大型シャーシの検証用経路を開始し、仲間が上層3室、はしご2本、地上へ連続して移動し、終了後に通常 AI へ戻ることを確認します。

静的な検証スクリプトは `tools/test_large_vehicle_layout.gd`、`tools/test_large_vehicle_workers.gd`、`tools/test_vehicle_prototype.gd` です。今回は Smart App Control の制約に従い Godot を起動していないため、インポート、テスト実行、実描画、Windows 上の入力操作はいずれも未検証です。
