## 今回の操作

中央交易都市へ移動して停泊し、下の「拠点 → 街に入る」を選ぶ。屋外の仲間がいれば、既存の呼戻しで帰還を待ってから開く。街を閉じると元の屋外方針に戻る。都市以外、走行中、襲撃中、仲間や荷物が帰還していない状態では取引しない。

独立した街画面に、自作の斜め俯瞰の砂漠交易都市、奥の門、左の交易所、右の市場、手前の給油タンク・ホース・クレーン・整備ヤードを配置。車体と部屋の窓・外装は既存の拠点データと素材を参照する。施設ラベルを押すと内容パネル、戻ると街、拠点へ戻ると通常画面。通常画面の上部に都市名ラベルは追加しない。ワールドマップは保持。

参考ページは施設選択の導線のみ：https://www.danball-senki.jp/wars/gamesystem/ 。画像・人物・固有施設の造形は転載していない。

街画面は世界の時間を停止し、開く前の停止状態を閉じる際に復元する。手動保存へ切り替える場合も停止を引き継ぐ。

## ミッションの分類

メインクエストはストーリー進行、サブクエストはアイテム・お金・装甲・仲間イベントなどによる総合的な強化でメイン攻略を楽にする役割。今回の納品・配達・都市手伝いはすべて繰り返し可能なサブクエストとして `TownDB.MISSIONS` に分類する。

メインのストーリー、ボス、仲間イベント、装甲ミッションの中身は今回追加しない。共通プレイヤーレベルや経験値は未指定なので作らない。「総合的成長」は装備・物資・人員などの充実の意味。サブ全達成をメイン進行の強制条件にせず、自由探索を維持する。街UIの入口は「交易所 / ミッション」。

## 経済とミッション（すべて試作値）

定義の入口は `data/town.gd`。通貨は共通クレジット Cr だけ、新規・旧保存の初期所持金は0。

| 操作 | 試作値 |
|---|---|
| 購入 | 食料4 / 燃料8 / 修理板8 Cr（各1個） |
| 売却 | 木材・石・生肉・皮・骨・脂肪は各2、鉄鉱石3 Cr。倉庫の未予約余剰だけ |
| 有料給油 | 25まで回復8 Cr。端数は実際の回復量から切上げ課金、上限100 |
| 有料修理 | 選択部位を25まで回復8 Cr。端数課金、各部位上限100 |
| 手持ちで整備 | 燃料1個で25、修理板1個で25回復。上限超過分は切捨てと表示 |
| 素材納品 | 木材3個 → 9 Cr。受注後、納品時だけ原子的に消費・受領 |
| 近距離配達 | 村への書状配達 → 都市帰還 → 20 Cr受領。現物アイテムを増やさずミッション記録で管理、積載0 |
| 街の手伝い | 仲間1人の荷札整理30秒 → 24 Crを明示受領 |

数量・単価・総額・所持金/在庫/燃料/耐久の変更後を見てから実行。発行した見積は1回だけ有効で、状態が変化した場合やロード後は実行不可。積載の加工予約も購入時に確認する。売却と納品は物理予約と既存の注文素材保護を差し引く。個体の装備・運搬中の品・作業場を直接売却対象にしない。仲間が給油/修理予約中の対象はサービスを拒否する。

ミッションはそれぞれ1件まで、受領後に繰り返し受注できる。取消は報酬なし、進捗・未受領報酬を破棄。自由探索に受注は不要。

### 手伝いの最小実装上の簡略化

街パネルから「勤務を開始 / 再開」で専用勤務表示へ移る。1人の名前と残り時間を示し、実時間で進める。この最小試作では仲間を通常AIの新職種へ配属せず、勤務表示中は世界・維持消費・採取・製作をすべて停止する等価処理。街の滞在支援を含む仕事としてUIに明記する。食料等の無料アイテムは配布しない。

中断は進捗保持、取消は破棄、ロード・街パネル・通常画面・終了中には仕事を自動進行しない。再開は明示操作。オフライン収益はなし。勤務完了だけでは通貨は増えず、交易所で明示受領する。

## 燃料15分 / 30分

`scripts/game_data.gd` の `FUEL_RANGE_MINUTES=15.0` を試作基準とする。容量100、標準速度60、距離消費を維持。30.0へ切り替えて比較可能。通常消費式は `走行距離 × 100 / (60 × 分数 × 60) × 天候倍率`。

| 条件 | 15分 | 30分（同距離から計算） |
|---|---:|---:|
| 標準走行・倍率1・追加補給なしの満タン | 900秒 | 1800秒 |
| 走行1秒あたり | 0.11111 | 0.05556 |
| 都市―村/砂原/鉱山入口往復4800、走行80秒 | 8.88889 | 4.44444 |
| 都市―鉱床往復7200、走行120秒 | 13.33333 | 6.66667 |

到着・帰還待ち、採取、天候減速は上の走行時間に含めない。停車の走行消費は0。寒波の暖房0.14〜0.30/秒と精錬3/回は既存値を維持し、整備画面で別消費として説明する。損傷による燃料漏れは増やしていない。

所感：現行の短い街道では15分でも都市―村の走行約11往復分あり、従来の約4分43秒より余裕が大きい。30分では約22往復分となり、燃料より暖房・精錬・耐久や食料が負担になりやすい。30分は同じ距離と式による比較であり、設定変更した長時間の別プレイ検証ではない。最終的な価格・移動距離・燃料バランスの確定はしていない。

## 保存

version3の任意項目 `town` に通貨、各ミッション状態、手伝い残り時間・担当者、受領累計を保存。旧v3の省略時は0 Cr・ミッションなし。負数・不正な進捗・担当者・状態を拒否し、適用は検査後のみ。見積券・進行中のUIタイマーは保存せずロードで無効化する。都市での保存は停泊位置と物資・進捗を維持し、ロード後は明示的に街へ入り直して勤務を再開する。

受領済み状態を読み直しても二重受領しない。ただし既存の手動セーブ全体を古い時点へ戻す操作を防ぐ外部台帳・不正防止機構は追加していない。

### 残る帰還制限

資源・燃料・所持金0、村→都市の低速15で、車体100なら160.2秒で帰還し車体88.786。車体5では71.6秒で時間摩耗により車体0となり、帰還前に敗北。天候・攻撃なしでも成立する反例であり、街外からの全状態の帰還は保証できない。全員が働けない状態も街の仕事で保証する対象ではない。

この点は途中報告済み。救援・負債・持ち物損失などの新規ルールは許可なしに追加しない。新たな救済仕様は次の判断事項。都市まで戻れて働ける仲間がいる場合の無資源・無燃料・無所持金復帰は確認済み。
