## 仮パラメータと操作

| 項目 | 値 |
| --- | --- |
| 奥／手前レーン | Y=350 / 470（間隔 120 px） |
| レーン接続 | X=485..595、幅 110 px の固定接続部 |
| 帰還 | 奥レーンの X=350 から固定スロープで後方拠点へ |
| 歩行・採取 | 90 px/s・1個につき 0.8 s |
| 搬送 | 1人あたり2個、鉄鉱石合計6個（各鉱脈2個） |
| 仲間 | ネズ吉、チュー太、モモ（3人） |

- `1`: 一列比較（全鉱脈を奥レーンに置く）
- `2`: 二レーン比較（奥・手前・奥に同じ3鉱脈を置く）
- `R`: ネズ吉だけを個人退却させる
- `A`: ネズ吉に手前レーンの敵への追跡を指示する
- `Tab` または上部の仲間名: 手前の個体の後ろにいる仲間を含めて選択する。クリックは選択だけで、採取移動・近接判定とは分離した。

描画は奥レーンを先、手前レーンを後に描き、各仲間・敵・鉱脈の足元影とレーン名を表示する。レーン変更は固定接続部への歩行のみで行い、フレーム内の瞬間移動はしない。仲間は鉱脈予約と同一レーンの最小間隔を使い、対向衝突による渋滞を作らない。
