## 比較条件と仮値

| 項目 | 値 |
| --- | --- |
| 奥/手前レーン | Y=350 / Y=470（間隔120 px） |
| レーン横断 | X=540 の同一平地上にある縦の固定横断路（長さ120 px） |
| 帰還 | 奥レーン X=350 から既存方式の固定スロープ |
| 歩行/採取 | 90 px/s / 1個あたり0.8秒 |
| 資源 | 各比較とも総量6個、各鉱脈2個 |
| 仲間 | ネズ吉、チュー太、モモ（3人） |

`1` は一列比較、`2` は固定2レーン比較、`R` は選択仲間の個人退却、`A` は別レーンの敵への追跡試験である。Tab・上部の仲間名・クリックで奥側を含む個体を選択できる。クリックは選択だけで、移動と近接命中の判定から分離している。

レーン変更は、同じレーンを固定横断路まで歩き、そこで縦に横断してから次の目的地へ進む。斜め抜け・瞬間移動・橋・斜路は使わない。レーン、描画順、足元影で奥/手前を区別する。描画UIは仲間名を短いボタンにし、選択中の状態は専用の4行表示へ分離して、拠点ラベルと重ならないことを実描画で確認した。

## 既存Worker/CharacterAIへの最小接続試験

`res://tools/test_two_lane_live_integration.gd` は模型AIではない。既存の `scenes/main.tscn`、`Worker`、`CharacterAI`、`GatherPoint`、`FieldOperations`、`Enemy` を使い、手前レーンに置いた1個の鉱脈を実際に処理する。

試験fixtureだけが `Main` の `ground_lane_config` メタデータで固定レーンを有効にする。通常マップはこのメタデータを持たないため、既存の地上移動は従来どおりである。固定レーンが有効な時だけ `Worker` は横断路まで同じレーンを歩き、縦に横断後、帰還時には既存スロープの足元へ向かう。

隔離 APPDATA / Godot 4.7.2 で次の10項目が成功した。

- 実際の `CharacterAI` が鉱脈を予約する。
- 実際の `Worker` が採取・所持・既存スロープ経由の帰還・荷卸しまで完了する。
- `FieldOperations` の納品数が増える。
- レーン横断を固定X=820の平地横断路として往復記録する。
- 実際の `CharacterAI` が攻撃命令を扱う。
- 同じXでも別レーンの敵には、横断前の近接攻撃が当たらない。
- 横断後には実際の近接命中が起きる。
- 個人退却中はレーン横断と既存スロープ経由で帰還する。
- 退却後に再攻撃・再採取しない。

これは既存基盤へ最小構成で載せられることの確認であり、通常マップへの展開ではない。全採掘地点への適用には、地形・セーブデータのレーン情報、敵を含む全エージェントの経路と衝突、深度を考慮した選択・命中、実OS入力での手動確認を別途設計・実装する必要がある。射撃・障害物・自由面移動・3D、資源量や報酬の増加は対象外である。
