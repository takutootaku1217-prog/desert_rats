## 最終の範囲と起動方法

現行は既存採取場所 `south_oasis` **だけ**の安全な opt-in 試作です。Godot のユーザー
引数に `two-lane-depth-prototype` を付けたときだけ有効になります。

```powershell
& '<Godot 4.7.2 console exe>' --path . -- two-lane-depth-prototype
```

通常起動、道路、他地域、移動拠点の走行・マップ、拠点内の階層／横移動、既存セーブの
座標には変更を加えません。3レーン、面状の自由移動、地形障害物、3D は対象外です。

| 項目 | 現行値 |
| --- | --- |
| 奥側の読みやすい停留位置 | world Y = 570 |
| 手前側の読みやすい停留位置 | world Y = 625 |
| 帯の深さ | 55 px |
| レーン間移動 | 任意 X で連続的・斜めに移動。固定 crossing X なし |
| UI との間隔 | NavigationBar 開始 Y=650 より手前側の足元 19 px 上 |

資源・野生生物・生態敵は `south_oasis` のみ両端アンカーへ配置されます。移動中は
アンカーにスナップせず中間 Y を通ります。既存 ramp は屋外と拠点の唯一の接続のままです。
Y-sort と足元影は既存描画を使い、同じ X の前後個体はクリック位置で選択します。
近接攻撃は物理 2D 距離で判定するため、同じ X でも別深さの敵には届きません。

## 保存復元の方針

保存形式のフィールド追加はありません。旗付き `south_oasis` の WorldTrip 管理資源・生物・
敵だけを `[570,625]` にクランプします。帯内の中間 Y は保持します。スロープ途中の個体、
屋内個体、道路・他地域の記録はそのままです。
