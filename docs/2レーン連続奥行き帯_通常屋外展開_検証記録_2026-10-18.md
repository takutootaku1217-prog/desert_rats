# 2レーン連続奥行き帯：通常屋外展開

確認日: 2026-10-18
作業先: `gpt/prototype-ground-two-lanes`（隔離 worktree。`main` には未統合）

## 実装範囲

通常起動の全公開地域・道路・採石場を、固定横断点ではない浅い連続奥行き帯へ移した。
屋内の階層移動、移動拠点の走行、マップ進行は変更しない。旧 `legacy-world-test`
起動経路は従来の自由な屋外 Y 座標を保つ。

| 項目 | 値 |
| --- | --- |
| 奥レーンの初期アンカー | world Y = 570 |
| 手前レーンの初期アンカー | world Y = 625 |
| 帯の幅 | 55 px |
| レーン間移動 | 任意 X で斜めに連続移動。固定 `crossing_x` なし |
| レーン数 | 2。3 レーンは未実装 |

資源・野生生物・生態系敵は初期配置時に二つのアンカーへ交互に置く。仲間と生態系敵は
対象の Y へ 2D 距離で接近するため、同じ X でも別の奥行きで即時近接命中しない。
帰還先が車内なら既存スロープ経路へ向かう。Y-sort、足元影、既存の位置クリック判定は
そのまま利用し、同 X の手前・奥の仲間を別々に選べる。

## 保存互換

保存形式のバージョンや新しい恒久フィールドは増やさない。ロード時だけ通常マップの
屋外レコード、可視ノード、階層 0 の仲間、採石場ポイントを 570/625 のいずれかへ
正規化する。屋内階層は保存された位置のまま。これにより過去の Y=630..680 の通常
屋外保存も読み込める。
