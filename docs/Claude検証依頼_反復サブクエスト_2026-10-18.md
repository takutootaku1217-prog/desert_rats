# Claude検証依頼：反復サブクエスト修正（2026-10-18）

対象コードは `508f24ac958bce5756ccdf3f8d683aa3838cd6d1`。証跡専用コミットとは区別し、ゲームコードの検証はこのSHAを基準にする。

確認対象は3件の既存反復依頼のみ。数値は木/石6→24 Cr、配達専用重量12→32 Cr・燃料10前渡、回収専用重量16→38 Cr、期限罰金なし。新しい敵予兆・3D・通常素材の追加/増殖は対象外。

1. East Sands へ停泊してからのみ、地上の回収荷物を既存スロープ経由で回収できること。甲板の横移動は許可し、地上敵は地上の担当者だけを止めること。負傷・撤退・現地断念で仲間が残留せず、別地域で拾わないこと。
2. 回収中はEast Sandsだけ出発を止めること。都市で古い現地状態が残っても恒久ロックしないこと。回収後は都市へ戻って38 Crを一度だけ受領できること。
3. 配達は交易村への通過では完了せず、停車して引渡すこと。町の説明・受注見積・フィールドHUDにも停車必須が出ること。
4. 燃料前渡しは実際の供与量で管理すること。満タン受注は0供与で未使用、部分空きは実供与量だけ、取消/再受注で増殖しないこと。
5. resource枯渇・採取狩猟OFF・Cr/燃料0からseed 811–813を各配達3+回収3周。食料消費、全パーツの実購入修理、速度回復、順序逆転での収支一致を確認すること。
6. フィールドと仲間パネルで、回収中/帰還/満載/警戒/配達停車必須が読めること。
