# 通常C帰還UI implementation plan

Goal: 通常C採掘でも右上の同じボタンで準備・待機・明示確定を行う。
Architecture: 既存任意前哨地の押下時操作/session/clock捕捉とcommit経路を再利用。地域ボスは対象外。
Scope: 仕様・資源・容量計算・保存形式は変更しない。中央出口と任意前哨地を維持。新ボタンは不要。
Alternatives: 中央出口の大型化は操作場所移動を残す。新ボタンは重複する。既存右上の限定拡張を採る。
Authorization: 継続開発と今回限定改善を親担当から引継ぎ。質問停止を避ける本人方針。
Spec: Notionの採用企画／詳細02／差分06 を今回再取得。帰還確認前の出発禁止、所在数量保持、固定停車と整合。

- [x] 押下跨ぎ・保存画面・古いclock・二重操作・容量確認取消を検査。
