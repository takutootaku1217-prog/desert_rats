# 2レーン相当・連続奥行き帯の小規模試作

確認日: 2026-10-18

## 最新仕様と範囲

- 屋外は固定された2本の線ではなく、**2レーン相当の浅い連続した帯**として扱う。
- 帯の任意の横位置から手前・奥へ直接移動できる。固定横断点、橋、段差、自由な3D面移動は使わない。
- 今回は通常 `Main` と既存 `Worker` / `CharacterAI` を接続する小規模試作だけであり、通常マップ全体・移動拠点の走行・地図・拠点内階層には展開しない。
- 3レーン化は未実施。資源量・報酬は増やしていない。

この最新仕様は、以前の固定横断点試作を置き換える。固定横断点版は未pushの保全ブランチにだけ残し、この試作からは利用しない。

## 仮パラメータ

| 項目 | 値 |
| --- | --- |
| 奥行き帯 | world Y `570..625`（55 px） |
| 拠点側 | 帯の奥側（Y=570） |
| 帰還 | 帯から既存の拠点スロープへ向かう |
| 近接命中 | 奥行きを含む実距離 `<= 46 px`（試作設定時のみ追加確認） |
| 通常の移動 | 既存の速度・AI状態機械を使用 |

帯に入っている間は屋外目標のYをこの範囲へ収め、目的地へ直接進む。帰還時は従来どおり `GameData.route_leg()` のスロープ経路を使う。固定 `crossing_x` は設定にも実装の有効経路にもない。

## 接続した役割

- 移動: `Worker.move_to_target()` の試作設定で、帯内目標へ直接・連続的に移動する。
- 描画: 既存 `ground_sort` のYソートと `Worker` の足元影をそのまま利用する。手前の個体ほど前に描く。
- 選択: 既存 `_pick_worker_at()` はスプライト領域内で足元に近い個体を選ぶ。重なり得る同Xの奥／手前個体を別々に選ぶ試験を追加した。
- 攻撃: 追跡は移動役割、近接命中は物理距離役割として分けた。奥行き差だけで届かない相手には即時命中しない。
- 退却: 個人退却は追跡・採取を再開せず、連続帯を抜けて既存スロープへ戻る。

## 検証

Windows Godot 4.7.2、隔離APPDATAで実行。

1. `tools/test_two_lane_prototype.gd`
   - 同一総量6の採取・運搬・スロープ帰還・荷卸し。
   - 奥行き移動が複数Xに現れ、固定横断点なし。
   - フレーム内の奥行き変化が移動量以内で、瞬間移動なし。
   - 近接個体を分離し、詰まりを作らない。
   - 同Xで奥行きが離れた敵への近接命中抑止、直接追跡、個人退却を確認。
2. `tools/test_two_lane_live_integration.gd`
   - 実 `Main` / `CharacterAI` で、前側鉱脈の予約、採取、荷卸しまで通過。
   - 同Xの奥／手前ワーカーを実ヒットテストで選択。
   - 同X・別奥行きの敵へ即時命中せず、直接奥行き移動で物理距離を詰めてから命中。
   - 個人退却後に再攻撃・再採取へ戻らない。

## 未実装・次段階

- 通常マップの全地域／街道・保存データには未展開。今回の小規模設定はメタデータを明示したときだけ有効。
- 地形障害物、射撃、3レーン、自由な面状探索は対象外。
- 全マップ展開は、この見た目・UI余白・選択感・退却感を確認してから別途段階的に判断する。
