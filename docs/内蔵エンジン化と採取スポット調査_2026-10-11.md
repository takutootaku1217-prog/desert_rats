# 小型拠点の内蔵エンジン化と採取スポット調査

2026-10-11。開始main `7d499fe5e68b3de65b8c2c384dd6d0d988a3a8fe`、origin/main `9f6be9a7f99b8d2f45f65119b7386463440e0e54`。既存の未push3コミットを保持。今回の実装は機関室変更だけ。以下の採取スポットは提案であり未実装。

## 実装した構成

- 可変4枠は維持。上階=加工室・寝室、下階=空き部屋・倉庫。操縦室・搬入口は固定。
- 小型拠点は内蔵エンジン。燃料・速度・消耗量は維持し、搬入口で燃料補給と走行装置の修理を行う。修理で自由枠内の旧座標へ向かう処理も解消。
- 空き1枠は医務室・食堂や部屋移設に使える。専用機関室の定義と任意建設・移設は保持。大型モデルへの必須化や解放条件はまだ実装していない。
- UIに内蔵エンジンと自由枠を説明。内装は既存の空き部屋画像を重ね、旧機関室を表示しない。
- 収納は既存倉庫（基本重量360、荷台3基で最大+180）のまま。ベッドは初期0台・最大3台。追加設備は加工室内ワークベンチ1＋物資庫1、寝室内ベッド3、倉庫内荷台3で最大8個。設備1個で部屋1枠を消費しない。

## 生活循環の確認範囲

- 食事: 満腹度は通常4/分減少、食料1個で+30、疲労-6、ストレス-12。食事によるHP回復はない（data/crew_status.gd）。実消費はconsumption_loopと長時間診断で確認。
- HP: ベッドで+0.7/秒、簡易休憩は休憩倍率、医務室で増幅。HP0では+0.35/秒でHP20に復帰。既存test_crew_statusで回復・復帰・AI休憩を確認。危険な場所で放置して生存できる保証ではない。
- 疲労: 活動で増え、待機では増えず、睡眠/簡易休憩で回復。車体不調は疲労回復を半減。敵に攻撃されても休憩を中断しない現仕様は残る。
- 停車: target_speed=0で既存資源を採れるが、距離依存の新規出現は止まる。空腹・車体摩耗・加工・出来事は進む。移動燃料と走行装置摩耗は止まるが、精錬はタンク燃料を使う。停車地点で食材が無限供給される機能はない。
- 長期滞在の食料収支、枯渇までの採取・出発・再訪はまだ通し検証の対象にできない（地点機能が未実装）。

## 採取スポットの土台と最小案（実装しない）

| 要素 | 現状と不足 |
|---|---|
| 採取資源 | GatherDB.POINTSに岩場・鉱床・枯れ木。鉱床残量6〜9、道具別効率、1回の袋3個、往復運搬がある |
| 停車採取 | GatherPoint.remainingが減る。ResourceNodeはscroll_speed=0なら流れない。画面内の既存ポイントを採る土台はある |
| 残量と再訪 | 残量はノード寿命中のみ。画面左へ流れるとqueue_free。地点ID・世界座標ごとの保存や再訪復元なし |
| 目的地選択 | 速度↑↓はあるが、目的地選択・到着判定なし。遺跡遠征UIは隊員を画面外へ送り報酬を受け取る別方式 |
| 出発と帰還 | 全員帰還待ち/出発ロックなし。速度変更は即時。採取予約・袋・屋外の仲間を引き上げる明示的な段階が必要。現行の遠征stop_work/arriveは物資返却/出現処理で、そのまま徒歩帰還として使えない |
| 重量と速度/燃料 | 拠点速度は目標・燃料有無・走行装置・天候で決まる。燃料は距離×1/170×天候倍率。重量への直接依存なし。仲間速度はHP/満腹度/疲労等による補正で、荷物重量に依存しない |
| 永続保存 | SaveGameは現mainに接続されていない旧コード。資源残量も保存せず、旧Balance.FABRIC参照エラーもある。再訪の永続化へそのまま転用できない |

第一弾の提案は「1地域・鉱石を持ち帰る1目標・2通りの準備」。固定の低リスク鉱床を選んで向かい、到着時に既存鉱床を有限量配置する。近い小採取群は短時間で必要量を回収、離れた密集群は往復が増える代わりに総量が多く、食事・休憩・倉庫空きを整えて長居する。道中の距離依存ランダム資源は別に維持する。軽装による加速/燃費ボーナスは提案へ混ぜない。

最小の新規部分は地点IDと有限残量の台帳、選択/移動/停車/帰還待ち/出発の状態、地点選択と残量・出発UI。選択解除や再訪で資源が復活しないこと、満載時の停止と空きができた後の再開、疲労/負傷中の帰還、運搬途中での出発、食料と修理資材の収支を検証する。近い/遠いが拠点までの移動距離か徒歩距離か、低リスク地点の天候/襲撃扱い、残量の保存期間、必要量による自動終了は親側で仕様決定が必要。生物戦闘・騎乗・中継地点・新素材・重量連動は今回追加しない。
