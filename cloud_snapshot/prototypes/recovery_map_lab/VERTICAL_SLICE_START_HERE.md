# C採石場・中継停車縦切り — Start Here

これは既存の `流動拠点サバイバル` に重ねる検証版です。別ゲームや
通常セーブの置換ではありません。基準は v13 累積 + v13 受入差分で、
この版では C採石場の通常3役分業にだけ `vertical_slice` を明示指定します。

## 起動

1. Godot 4.7.2 で `project/` を開き、ローカルの `.godot/` import cache を
   作る。クラウドの `.godot/` はコピーしない。
2. `res://scenes/recovery_route_bridge_launcher.tscn` を実行する。
3. 右上の **「中継停車 縦切りでA→C（検証）」** を押す。
4. 固定クォータービューで **整備** → 整備完了後に **中継停車** を押す。
   現在の貨物だけを回収してから中継停車へ移り、通常3役の回収を再開する。

通常分業と単独追跡の入口は別のままで、`vertical_slice` を渡さない
session の挙動は変更しない。

## この縦切りで確認する操作

- 入口停車は片道24秒、中継停車は片道14秒の設定値。
- 小障害物の整備が終わるまでは中継停車を拒否。
- 停め直し中は新規採取を止め、運搬中の貨物も relay → 搬入口へ回収。
- 満載時は新規採取を停止し、入りきらない貨物を仲間が保持する。容量更新後は
  保持貨物を一度だけ収納し、通常分業を再開する。撤退／停め直し中なら、
  役割再開よりその指示を優先する。
- **停車取消**、経路閉鎖／再開、検証保存／読込、通常の**撤退**も試す。

`検証保存` は project-local fixture 用であり、通常の `user://` セーブは
この launcher 内で無効化している。

## v15.4 の表示契約

- **入口**では既存の同向き車体と階段の接点に荷下ろしを投影する。
- **中継停車**は、全員と現在の貨物が帰還して session の `parking_slot` が
  確定した後だけ、同じ既存車体レイヤーを中継 dock へ移す。停め直し中は入口の
  車体を保持し、HUD は「中継へ回収中」と表示する。
- 中継 dock は短橋の手前を覆わない位置に作者定義しており、通常の主経路が通る
  間は未使用の入口→橋迂回帯を描かない。主経路を閉鎖した場合だけ、既存 session の
  迂回路を再表示する。relay の編成許容帯が既存 endpoint と重なる時も、移動役は
  最近傍の source centreline を選ぶため、境界で表示位置が跳ばない。

これは走行アニメや座標の第2正本ではなく、将来置換可能な二つの停車 pose である。
資源、貨物、collision、経路、保存の正本は既存 session のままである。

v9 は 1280×720、64.0秒、639/64fps（約9.984fps）、639 decoded frames。ボタンはクラウドで
対応した物理クリック注入器がないため、同じ本番 callback への
`Button.pressed` 信号で操作した。これは Windows の物理マウス、音声、性能、
Godot 4.7.2 の合格を意味しない。
